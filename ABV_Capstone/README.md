Core objective is to use an accounting-based valuation model (residual income or abnormal earnings growth) to:
- Decompose a company’s current market valuation
- Compare it to forecasts and analyst expectations
- Arrive at a supported buy / sell / hold recommendation

Do this by:
- Pulling and processing financials using current stock ticker
- Making assumptions (ROE, payout, WACC)
- Reverse-engineering what the market is implying
- Comparing those market-implied expectations to analyst forecasts
- Presenting findings and recommendation
